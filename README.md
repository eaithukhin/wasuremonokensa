# 🔍 Item Finder App (wasuremonokensa)

A practical web application inspired by the daily stress of misplacing essential items like keys or wallets before leaving the house. 

## 🚀 Live Demo
Experience the live application here: [https://eaithukhin.github.io/wasuremonokensa/](https://eaithukhin.github.io/wasuremonokensa/)

## ✨ Key Features
- **Barcode Scanning:** Scan barcodes to register and track personal belongings instantly.
- **Automated GPS Tracking:** Automatically captures and records the precise GPS coordinates of an item at the time of scanning.
- **Geolocation Mapping:** View the last known location of your registered items plotted directly onto an interactive map.

## 🛠️ Tech Stack & Libraries
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Database & Backend:** Firebase Firestore (Cloud NoSQL Database)
- **Mapping API:** Leaflet.js (Interactive maps for location history tracking)
- **Hardware Integration:** Html5-Qrcode (In-browser camera barcode scanning)

## 💡 Project Background & Learning Outcomes
This project originated from a personal desire to solve a common daily inconvenience using modern web technologies. 

As my first real-world utility application built outside of classroom assignments, I chose **Firebase Firestore** to gain practical experience with cloud databases. It provided a scalable, configuration-light environment that allowed me to focus heavily on front-end asynchronous operations and hardware APIs (Camera & GPS). This project represents my proactive approach to self-learning, debugging, and transforming conceptual ideas into a working product.
